  2. Select Class A (Linear) and set Input Drive to 3.0 V. Watch Conduction Angle display 360° (Full Cycle Conduction), Threshold Deadband disable with note N/A (Class A: continuous conduction), and Distortion Status display < 0.5% (Clean Linear). Why: Continuous conduction over the complete 360-degree input cycle prevents crossover dead zones.

Why It Matters

Class A burns maximum heat when no audio is playing. Class B draws zero quiescent power, but crossover distortion sounds harsh to human ears. Class AB combines the efficiency of Class B with the low distortion of Class A.
