About This Project

Analog Circuits Odyssey is an independent, unofficial educational web platform created by Karthik Shenoy for students studying 25ECE211 Analog Electronic Circuits.

The project combines WebGL 3D semiconductor physics chambers, virtual dual-trace oscilloscopes, a small-signal circuit analysis studio, a thorough searchable formula table, and worked step-by-step problem solvers.

The 3D semiconductor carrier concept was inspired by Transistor Odyssey, created by Norman's Rule. Transistor Odyssey is credited here as design inspiration only; all code and curricular implementations in this project were created independently.
